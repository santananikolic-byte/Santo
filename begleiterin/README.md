# Lena – KI-Begleiterin

Eine einzelne Datei (`index.html`), die im Browser läuft.

1. `index.html` in **Chrome oder Edge** öffnen (Doppelklick reicht).
2. Beim ersten Start den Claude-API-Schlüssel eintragen (console.anthropic.com).
3. Unter ⚙︎ Name, Persönlichkeit, Stimme und Sprechtempo anpassen.
4. Schreiben oder 🎤 drücken und sprechen. Sie antwortet mit Stimme (🔊 schaltet das aus).

Der Verlauf und der Schlüssel werden nur lokal im Browser gespeichert.
Tipp: Die natürlichsten deutschen Stimmen haben Edge ("Microsoft Katja/Amala Online (Natural)") und Chrome ("Google Deutsch").
