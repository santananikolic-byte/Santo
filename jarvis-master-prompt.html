Memory layers

Current conversation, active tasks and immediate context.

BLong-term memory

Important information retained across conversations and restarts.

CProject memory

Separate knowledge bases for every project.

DOperational memory

What you have done, when you did it, which tools you used and what happened.

Development Methodology

Build the real system

Do not deliver a superficial prototype and claim that the complete system exists. Develop the actual working application. Follow this process:

PHASE 1 – SYSTEM ANALYSIS

Inspect the existing development environment. Identify: available hardware, operating system, installed dependencies, existing repositories, available API credentials, available infrastructure, existing code, technical limitations.

Do not destroy or overwrite existing work.

PHASE 2 – ARCHITECTURE

Design the complete technical architecture. Define: modules, services, database schemas, APIs, agent interfaces, permissions, data flows, security boundaries, deployment structure.

PHASE 3 – CORE IMPLEMENTATION

Build the actual foundation: authentication, dashboard, backend, database, persistent memory, AI provider integration, agent orchestration, task management, logging, approval system.

PHASE 4 – BUSINESS MODULES

Implement: customer management, market research, financial management, email integration, calendar integration, project management, business intelligence, notifications.

PHASE 5 – ADVANCED CAPABILITIES

Implement: multi-agent programming, parallel task execution, browser automation, voice interface, video meeting support, self-analysis, automated quality assurance, advanced reporting.

PHASE 6 – TESTING

Test every module. Include: unit tests, integration tests, end-to-end tests, security tests, permission tests, recovery tests, performance tests.

Do not mark unfinished or untested modules as completed.

PHASE 7 – DEPLOYMENT

Prepare: production configuration, installation instructions, environment configuration, database migrations, backup procedures, startup scripts, monitoring, recovery documentation.

The system must be installable, maintainable and expandable.
